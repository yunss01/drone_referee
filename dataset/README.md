# 로컬 입력 데이터

영상과 학습 이미지는 로컬에 보존하며 이 README 외에는 GitHub에 올리지 않습니다.

- `3배_1.MP4` ~ `3배_4.MP4`: 원본 영상, 1920×1080, 약 59.94fps.
- `3배_1_15fps.mp4`, `3배_1_30fps.mp4`: FPS 비교용 변환본.
- `편집본/test_1.mp4` ~ `편집본/test_12.mp4`: 전체 구간 비교 실험용 편집본, 1920×1080, 30fps.
- `drone_lane/`: 이전 차선 연구용 이미지·라벨 자료.

입력 파일은 이번 폴더 정리로 이동하거나 변경하지 않았습니다. 특허 비교 실험 코드와 CSV는 루트의 `특허용 자료들/`에 별도로 보존합니다.
