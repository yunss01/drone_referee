# 로컬 보관 자료

현재 운영에 직접 사용하지 않는 자료를 삭제하지 않고 이 폴더로 옮겼습니다. 이 README 외의 내용은 GitHub에 올리지 않습니다.

| 하위 폴더 | 내용 |
| --- | --- |
| `lane_model_trials/PINet_new/` | PINet 기반 비교 연구 |
| `lane_model_trials/UnLanedet/` | UnLanedet 기반 비교 연구와 결과 |
| `experiments/CLAHE_test/` | CLAHE 단독 실험과 이미지 |
| `experiments/test.py` | 이전 색상 기반 바퀴 판정 실험 |
| `paper_figures/` | PCA 그림 생성 코드, 예제 이미지와 결과 |
| `results/test_results/` | 이전 판정 CSV와 결과 이미지 |

보관 코드는 당시의 상대 경로나 외부 서비스 설정을 포함할 수 있습니다. 재실행 전에 경로를 확인합니다. 운영 코드가 이 자료를 import하거나 실행하지는 않습니다.

전체 이동 내역은 [폴더 정리 문서](../docs/repository_layout.md)를 참고하세요.
